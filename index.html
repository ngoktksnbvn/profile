01

Giới thiệu

Tôi có 3 năm kinh nghiệm Full Stack Developer, phát triển Back-end với Python (Flask), Node.js (Express.js) và PHP (Laravel), xây dựng RESTful API, xử lý logic nghiệp vụ, phân quyền người dùng và làm việc với MySQL (thiết kế schema, tối ưu truy vấn và tối ưu hiệu năng cơ sở dữ liệu).

Có kinh nghiệm phát triển Front-end với JavaScript (ES6+), TypeScript, Vue.js, React.js và Next.js, xây dựng giao diện bằng HTML5/CSS3, tối ưu UI/UX, Responsive Web Design, tích hợp API và cải thiện hiệu năng ứng dụng.

Có kinh nghiệm làm việc trực tiếp với khách hàng để trao đổi nghiệp vụ, khảo sát hiện trạng, tiếp nhận và phân tích yêu cầu, làm rõ yêu cầu hệ thống, đề xuất giải pháp kỹ thuật, thiết kế chức năng và triển khai phát triển các tính năng đáp ứng yêu cầu thực tế của dự án.

Có kinh nghiệm sử dụng Docker để containerize ứng dụng, xây dựng môi trường development, triển khai các service và làm việc trên môi trường Linux, sử dụng Git (GitHub, GitLab) để quản lý mã nguồn và cộng tác phát triển phần mềm.

Ngoài ra, tôi có kinh nghiệm xây dựng các hệ thống Automation và Workflow Automation, thu thập dữ liệu bằng Python (Requests, Selenium), xử lý các luồng nhiều bước, duy trì Session/Cookie, xử lý CAPTCHA, chuẩn hóa, kiểm tra, xử lý và đồng bộ dữ liệu giữa nhiều hệ thống.

Tôi có tư duy automate-first, thiết kế các pipeline xử lý dữ liệu end-to-end (crawl → xử lý → đồng bộ), áp dụng Retry Pattern, Idempotency, Logging, tối ưu Throughput, Latency và khả năng mở rộng của hệ thống.

Có kinh nghiệm sử dụng AI/LLM (Cursor, ChatGPT, GitHub Copilot) để tăng tốc phát triển phần mềm, hỗ trợ viết mã, debug, tối ưu mã nguồn và nâng cao năng suất làm việc. Ngoài ra, tôi có kinh nghiệm xây dựng dashboard và trực quan hóa dữ liệu bằng Apache Superset phục vụ thống kê và phân tích dữ liệu.

Kỹ năng

Back-end Python · Node.js · PHP

Có kinh nghiệm phát triển Back-end với Python (Flask), Node.js (Express.js) và PHP (Laravel). Xây dựng RESTful API, xử lý logic nghiệp vụ, phân quyền người dùng, tích hợp hệ thống, tối ưu hiệu năng ứng dụng và làm việc với MySQL (thiết kế schema, tối ưu truy vấn, xử lý dữ liệu lớn).

Front-end VueJS · ReactJS · Next.js

Có kinh nghiệm phát triển giao diện với Vue.js, React.js và Next.js sử dụng JavaScript (ES6+), TypeScript, HTML5, CSS3. Xây dựng giao diện Responsive, tối ưu UI/UX, tích hợp RESTful API, phát triển các module nghiệp vụ và cải thiện hiệu năng ứng dụng.

Data & Automation Python · Selenium · N8N

Xây dựng hệ thống crawl dữ liệu từ nhiều nguồn website bằng Python (Requests, Selenium), duy trì session/cookie và CAPTCHA. Làm sạch, kiểm tra, xử lý và đồng bộ dữ liệu giữa các hệ thống qua Workflow Automation và pipeline (Crawler → Processor → Sync).

DevOps & System Docker · Linux · Git

Sử dụng Docker để containerize ứng dụng và xây dựng môi trường development. Có kinh nghiệm làm việc trên môi trường Linux, viết script bash cơ bản, CI/CD, sử dụng Git (GitLab, GitHub) theo quy trình Agile/Scrum.

Data Visualization Apache Superset

Có kinh nghiệm xây dựng dashboard và trực quan hóa dữ liệu bằng Apache Superset, phục vụ thống kê, phân tích và theo dõi dữ liệu từ các hệ thống thu thập. Tích hợp WSO2 Identity Server phục vụ xác thực và phân quyền.
